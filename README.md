## 🚀 Modules & Progress

### 01. Python Basics & Algorithmic Problem Solving

* **Task 1: Fundamentals & Mathematical Operations**
* Console I/O and string formatting (`sep`, `end` parameters).
* Arithmetic operations, fractional division, and unit conversions.
* Coordinate math: Euclidean distance calculation with Matplotlib visualization.


* **Task 2: Conditionals & Iterative Logic**
* Multi-bracket conditional evaluations (tax estimation, triangle validity).
* Iterative sequence processing: Fibonacci generation, factorials, and digit reversal.
* Number theory implementations: Prime detection optimized to $\mathcal{O}(\sqrt{n})$ and Armstrong number verification.


* **Task 3: Pattern Printing, Series & String Processing**
* Coordinate-based star patterns and symmetric pyramid generation using nested loops.
* Numerical series approximations (logarithmic expansions and power series).
* Arithmetic algorithms: Euclidean algorithm for GCD/HCF and LCM derivation.
* String manipulation: In-place digit extraction, word frequency analysis, palindrome/symmetry checks, and order-preserving deduplication (`dict.fromkeys`).



### 02. Data Structures & Algorithms (`02-DSA`)

* Core Python data structures (lists, tuples, sets, dictionaries) and algorithmic complexity practice.

### 03. Object-Oriented Programming (`03-OOP`)

* **Day 1 — Classes, Objects & Magic Methods:** Instance attributes, constructors (`__init__`), custom dunder methods (`__str__`, `__add__`, `__sub__`, `__mul__`, `__truediv__`), and coordinate geometry (`Point` & `Line`).
* **Day 2 — Encapsulation, Composition & Static/Class Methods:** Private attributes with getters/setters, static counters (`ATM`, `Car`), `@classmethod` factories (`Rectangle`), `datetime` expiry tracking, and object composition (`Card`/`Deck`, `Scoop`/`Bowl`).
* **Day 3 — Inheritance, Polymorphism & Abstraction:** Class hierarchies (`IS-A` relationships), constructor chaining (`super()`), method overriding, and abstract base classes (`abc`).

### 04. Numerical Computing & Data Manipulation (`04-numpy-pandas`) *(Upcoming)*

* Vectorized array operations with NumPy and tabular data wrangling/EDA with Pandas.

### 05. Relational Databases & Querying (`05-SQL`) *(Upcoming)*

* Schema design, joins, aggregations, subqueries, and window functions for analytics.
