## 🚀 Modules & Progress

### 01. Python Basics & Algorithmic Problem Solving

* **Task 1: Fundamentals & Mathematical Operations**
  * Console I/O and string formatting (`sep`, `end` parameters).
  * Arithmetic operations, fractional division, and unit conversions.
  * Coordinate math: Euclidean distance calculation with Matplotlib visualization.

* **Task 2: Conditionals & Iterative Logic**
  * Multi-bracket conditional evaluations (tax estimation, triangle validity).
  * Iterative sequence processing: Fibonacci generation, factorials, and digit reversal.
  * Number theory implementations: Prime detection optimized to $\mathcal{O}(\sqrt{n})$ and Armstrong number verification.

* **Task 3: Pattern Printing, Series & String Processing**
  * Coordinate-based star patterns and symmetric pyramid generation using nested loops.
  * Numerical series approximations (logarithmic expansions and power series).
  * Arithmetic algorithms: Euclidean algorithm for GCD/HCF and LCM derivation.
  * String manipulation: In-place digit extraction, word frequency analysis, palindrome/symmetry checks, and order-preserving deduplication (`dict.fromkeys`).
